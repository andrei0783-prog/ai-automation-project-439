# Автоматизация разбора файлов


[![hexlet-check](https://github.com/andrei0783-prog/ai-automation-project-439/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/andrei0783-prog/ai-automation-project-439/actions)

Напишите консольную программу на JavaScript, которая разбирает папку с документами
компании: определяет тип каждого файла, находит дубликаты, отделяет полезные документы
от посторонних и собирает реестр. Отдельная команда сводит выгрузки контактов из разных
источников в одну таблицу — приводит колонки к единому виду, нормализует телефоны
и email, убирает повторы.

Учебный проект Хекслета: https://ru.hexlet.io/programs/ai-automation


## Стек

- JavaScript

## Установка

Понадобятся Git и Node.js 24 с npm. Выполните в терминале:

```bash
git clone https://github.com/andrei0783-prog/ai-automation-project-439.git
cd ai-automation-project-439
npm ci
npm link
```

`npm ci` устанавливает зависимости, а `npm link` делает доступной команду
`file-automation`.

## Использование

Показать справку:

```bash
file-automation --help
```

Запуск без аргументов также выводит справку:

```bash
file-automation
```

Показать версию:

```bash
file-automation --version
```

Если вы не выполняли `npm link`, запустите справку из папки проекта напрямую:

```bash
node bin/file-automation.js --help
```

## Входные данные

Учебную папку компании возьмите из материалов задания курса Хекслета и поместите
в корень проекта под именем `company-files`. Эта папка не входит в репозиторий.
Можно использовать свою папку с документами и выгрузками контактов, указав её
путь вместо `./company-files`. Обе команды обходят все подпапки.

Контакты читаются из непустых CSV и JSON. CSV содержит заголовок и строки данных,
разделитель — запятая или точка с запятой. JSON — массив объектов.
Выгрузкой контактов считается таблица с колонкой телефона или почты:
`телефон`, `моб. телефон`, `phone`, `почта`, `e-mail` или `email`.

## Обработка файлов

```bash
file-automation files ./company-files --out ./out
```

Команда определяет типы и статусы файлов, находит дубликаты и создаёт:

- `out/registry.csv` — реестр всех файлов с путями, типами, размерами, хешами,
  статусами, основными копиями, количеством строк и колонками таблиц;
- `out/report.txt` — сводку, списки файлов для ручного разбора и удаления,
  группы дубликатов с лишним размером в байтах;
- `out/report.json` — те же сведения в структурированном формате для программ.

Пути в списках отчёта указаны относительно исходной папки компании.
Основная копия выбирается по сортировке пути; какую копию оставить, решает человек.

## Обработка контактов

```bash
file-automation contacts ./company-files --out ./out
```

Команда нормализует имена, телефоны и почту, объединяет записи по телефону
или, при его отсутствии, по почте. Создаются:

- `out/contacts.csv` — уникальные контакты с колонками `имя`, `телефон`, `почта`,
  `источники`;
- `out/report.txt` — число записей до и после склейки, отбракованных значений,
  записей без телефона и почты, список выгрузок с количеством записей;
- `out/report.json` — те же сведения в JSON.

Папка результата создаётся автоматически. Без `--out` используется `./out`.
Укажите папку результата вне исходной папки, чтобы результаты не попадали
в следующий обход. Исходные документы программа не изменяет.
Отчёты `report.txt` и `report.json` перезаписываются последней запущенной командой.
Чтобы сохранить отчёты обеих команд отдельно, используйте, например,
`--out ./out/files` и `--out ./out/contacts`.

Без `npm link` команды запускаются через `node bin/file-automation.js`, например:

```bash
node bin/file-automation.js files ./company-files --out ./out
node bin/file-automation.js contacts ./company-files --out ./out
```
